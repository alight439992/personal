# 个人展示网站需求文档（PRD）

## 1. 项目目标
制作一个深色星空风格的个人展示网站，支持展示个人信息、技能、项目、博客和联系入口，并提供简单的后台管理功能。

## 2. 页面结构
- 首页：Hero 欢迎区、个人简介、技能、项目、最新文章、联系入口。
- 博客列表：展示文章标题、摘要、日期和标签。
- 博客详情：展示单篇文章内容。
- 联系页面：联系表单演示。
- 后台登录：`/admin`。
- 后台管理：仪表盘、个人资料、技能、项目、博客文章和网站设置。

## 3. 功能需求
- 前台数据从统一 API 模块读取。
- 后台需要登录后访问；演示账号 admin / admin123。
- 支持项目、技能、博客文章的新增、编辑、删除。
- 个人资料与网站设置可保存。
- 联系表单进行前端校验并展示提交成功反馈。
- 数据使用 localStorage 模拟持久化，不需要后端服务。

## 4. 视觉要求
深色星空背景、紫蓝色渐变点缀、卡片式布局、响应式设计，兼容桌面与移动端。

## 5. 验收标准
- 前台页面能正常访问。
- `/admin` 登录后能进入后台。
- 后台数据新增、编辑、删除后刷新仍然保留。
- 未登录访问后台管理页面会被引导至登录页。
- `npm run build` 可完成构建。
